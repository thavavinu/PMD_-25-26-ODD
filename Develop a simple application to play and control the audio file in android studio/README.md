# EXPERIMENT 3 – AUDIO PLAYER CONTROL IN ANDROID

## AIM
To develop a simple Android application to play and control an audio file by performing Start, Pause, and Stop operations.

## EQUIPMENTS REQUIRED
- Android Studio (Minimum required version: Arctic Fox)

## ALGORITHM

**Step 1:** Open Android Studio and click **File → New → New Project**.

**Step 2:** Enter the application name as `AudioFile` and click **Next**.

**Step 3:** Select the minimum SDK version and click **Next**.

**Step 4:** Select **Empty Activity** and click **Next**. Finally, click **Finish**.

**Step 5:** Design the layout in `activity_main.xml` and create Start, Pause, and Stop buttons.

**Step 6:** Implement the audio playback and button-control functionality in the `MainActivity` file.

**Step 7:** Save and run the application to verify the Start, Pause, and Stop operations.
